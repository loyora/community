## À propos

Loyora aide les propriétaires à gérer leurs biens en location au quotidien.

Ici, vous pouvez :

- **signaler des bugs** ;
- **proposer de nouvelles fonctionnalités** ;
- **poser vos questions et échanger** avec l'équipe et les autres utilisateurs.

Vos retours décident directement de ce que nous construisons ensuite. Merci d'avance !

## Signaler un bug

1. **Cherchez d'abord** dans les [issues existantes](https://github.com/loyora/community/issues?q=is%3Aissue) : le bug a peut-être déjà été signalé. Si c'est le cas, ajoutez un 👍 ou un commentaire avec vos informations.
2. Sinon, **[ouvrez une nouvelle issue](https://github.com/loyora/community/issues/new?labels=bug)** en précisant :
   - **Description** : ce qui ne fonctionne pas ;
   - **Étapes pour reproduire** : 1. … 2. … 3. … ;
   - **Résultat attendu** et **résultat obtenu** ;
   - **Environnement** : appareil, système, navigateur ou version de l'app ;
   - **Captures d'écran** ou vidéo si possible.

> [!WARNING]
> **Ne partagez jamais de données personnelles** dans une issue : noms ou coordonnées de locataires, IBAN, baux, quittances ou autres documents. Floutez vos captures d'écran si besoin. Ce dépôt est **public**.

## Proposer une fonctionnalité

1. Vérifiez si l'idée a déjà été [proposée](https://github.com/loyora/community/issues?q=is%3Aissue+label%3Aenhancement). Si oui, **votez avec un 👍** : ça nous aide à prioriser.
2. Sinon, **[ouvrez une demande](https://github.com/loyora/community/issues/new?labels=enhancement)** en expliquant :
   - **Le besoin** : quel problème rencontrez-vous ? Décrivez-le plutôt que de proposer directement une solution ;
   - **Un cas concret** : « Quand je fais…, j'aimerais pouvoir… » ;
   - **Comment vous faites aujourd'hui**, si vous avez trouvé une solution de contournement.

> [!TIP]
> Votre idée n'est pas encore très claire ? Lancez plutôt une [discussion](https://github.com/loyora/community/discussions/categories/idees) pour en parler d'abord.

## Discussions

Les [Discussions](https://github.com/loyora/community/discussions) servent à tout ce qui n'est ni un bug ni une demande précise :

| Catégorie       | Pour quoi faire                                                     |
| --------------- | ------------------------------------------------------------------- |
| 📣 **Annonces** | Nouveautés, mises à jour et feuille de route de Loyora              |
| 🙋 **Q&A**      | Questions sur l'utilisation de l'app, entraide                      |
| 💡 **Idées**    | Idées encore floues, à affiner avec la communauté                   |
| 🗣️ **Général**  | Retours d'expérience, conseils de gestion locative, échanges libres |

## Sécurité

Vous avez trouvé une faille de sécurité ? **N'ouvrez pas d'issue publique.**
Écrivez-nous en privé à **[security@loyora.io](mailto:security@loyora.io)**. Nous vous répondrons le plus vite possible.

## Code de conduite

Cet espace est ouvert à tous. Merci de rester **bienveillant, respectueux et constructif** dans vos échanges. Nous nous réservons le droit de masquer ou supprimer tout message insultant, discriminatoire ou relevant du spam, et de bloquer les auteurs concernés.
